# 双视角教学量测台

加载两张无畸变图片与已知相机参数（K、R、t），在页面上标记最多 20 对对应点，
后端完成三角化，页面显示空间点与两图重投影。

**外参约定（固定）**：`X_camera = R · X_world + t`（相机中心 `C = −Rᵀt`）。

## 运行

```bash
pip install -r requirements.txt
python3 demo/make_demo.py     # 生成演示图片与相机参数（已生成可跳过）
python3 server.py             # http://127.0.0.1:8000
```

## 使用

- 左键单击＝加点（按加入顺序自动配对，每视图最多 20 点）；右键＝删除最近点；
  滚轮＝以光标为中心缩放；按住拖动＝平移；「复位视图」恢复适配。
- 所有量测点都以**原图像素坐标**保存并携带图片身份（视图 1/2）；
  屏幕/CSS 坐标只用于显示，经视图逆变换还原后才成为量测。
- 填写/确认 K1、R1、t1、K2、R2、t2（JSON），设定两图共用的像素误差上限与噪声 σ，
  点击「三角化」。结果表给出空间点、两图各自重投影误差、射线夹角与
  局部协方差 σ²(JᵀJ)⁻¹；图上叠画青色 × 为重投影。
- **任何对对应点或相机参数的编辑都会撤销旧结果。**

## 后端算法（`triangulation.py`）

1. 校验相机矩阵：K 上三角且焦距为正、R 正交且 det=+1、t 为三维向量；
2. Hartley 归一化 DLT 求初值（归一化相似变换由该视图全部对应点估计）；
3. 自写阻尼最小二乘精化：解析重投影雅可比 + Levenberg 阻尼 + 下降检查，
   有限次迭代（默认 50）；只用 NumPy 的 SVD/线性求解，
   不调用现成三角化或非线性优化函数；
4. 拒绝并给出具体原因：射线夹角距 0°/180° 小于 0.5°（`RAY_ANGLE`）、
   秩不足（`RANK_DEFICIENT`）、点位于任一相机后方（`BEHIND_CAMERA`）、
   未收敛（`NOT_CONVERGED`）、重投影误差超用户上限（`PIXEL_ERROR`）；
5. 通过者返回同一次求解的重投影、两图误差与 3×3 **局部**协方差
   σ²(JᵀJ)⁻¹（假设各像素坐标独立同方差 σ 噪声；为当前解处的线性化估计，
   **不构成全局可信保证**）。

服务无状态：不做持久化，不做自标定（K/R/t 只校验、不修改）。

## 测试

```bash
python3 -m pytest tests/ -q
```

- `tests/test_triangulation.py`：已知三维点独立投影还原、轻微噪声、
  近共线射线（近 0° 与近 180°）、反向相机（点在相机后方）、相机校验、
  误差上限、20 对上限、不收敛、DLT 秩不足、同次求解一致性；
- `tests/test_browser.py`：一次完整浏览器流程——缩放/平移后点击，
  断言记录的是原图像素坐标而非 CSS 坐标；后端返回的原图坐标
  （重投影/空间点）正确且叠画位置正确；编辑后旧结果作废。
  （本环境 Chromium 的系统库解包在 `/tmp/chromelibs`，测试内已自动
  设置 `LD_LIBRARY_PATH`。）


标定量测：访问 /measurements。/api/measurements 在原三角化参数之外接收 reference=[原始编号,原始编号]、known_length>0、segments（1～8 对）。输入各点噪声独立，但不同线段复用同一端点时必须视为同一随机变量。已知物理参考长度按精确值处理；参考段测自己应返回该长度及零方差。任一引用被拒绝的点、零长度或非法参数时整次量测失败。输出保留三角化证据与每个原始端点的局部导数。
